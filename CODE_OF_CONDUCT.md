# Code of Conduct

ForgeSense AI welcomes rigorous technical collaboration conducted with respect.

## Expected behavior

Contributors and maintainers are expected to:

- discuss technical disagreements using evidence and reproducible results;
- review code, designs, and research claims rather than attack people;
- acknowledge uncertainty and correct mistakes when evidence changes;
- respect confidentiality around private security and intellectual-property work;
- credit sources, prior work, datasets, and contributors accurately;
- avoid discriminatory, harassing, threatening, or demeaning behavior;
- avoid publishing another person's private information without permission;
- keep safety discussions factual and conservative.

## Unacceptable behavior

Harassment, intimidation, deliberate disruption, plagiarism, fabricated test data,
misrepresentation of results, unauthorized disclosure of private project material,
or attempts to bypass repository security controls are not acceptable.

## Enforcement

The repository owner may edit or remove content, restrict participation, revoke
access, or reject contributions when behavior threatens collaboration, safety,
security, research integrity, or project confidentiality.

Concerns should be reported privately to the repository owner. Reports will be
handled as confidentially as practical.
