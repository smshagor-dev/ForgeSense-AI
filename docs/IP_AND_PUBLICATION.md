# Intellectual Property, Prior Art, and Publication Discipline

## Why this matters

ForgeSense AI is intended to explore potentially differentiating system-level
ideas. Publishing detailed implementation material before deciding an IP strategy
can affect what can later be protected in some jurisdictions.

This document is an engineering policy, not legal advice.

## Current repository posture

The repository is private and uses an all-rights-reserved development license.
Do not copy project material into public repositories, public presentations,
preprints, social posts, public demos, or external datasets without an explicit
publication decision.

## Novelty claims

Do not write "first", "world's first", "never existed", "unique", "patented",
or equivalent claims unless a documented prior-art review and appropriate legal
review support the exact statement.

Prefer precise statements describing what the system actually implements and how
it differs from cited related work.

## Prior-art review

Before a strong novelty claim or patent filing decision, search at minimum:

- academic literature;
- patents and published applications;
- FPGA-based condition monitoring systems;
- edge/TinyML predictive-maintenance systems;
- safety PLC and FPGA safety architectures;
- ML safety wrappers and runtime assurance;
- industrial condition-monitoring products;
- relevant open-source projects.

Record search terms, databases, dates, closest references, overlapping claims,
and remaining differentiators.

## Invention records

For a potentially protectable technical contribution, record privately:

- problem being solved;
- prior approaches known at the time;
- precise technical mechanism;
- inventors/contributors;
- earliest dated implementation or experiment;
- diagrams and test evidence;
- alternatives considered;
- public disclosures, if any.

## External contributions

Do not accept third-party material whose ownership or license is unclear. Keep
contributor provenance traceable.

## Publication readiness

Before public technical disclosure, decide:

1. what material can be public;
2. whether any protection should be filed first;
3. what license applies to each public artifact;
4. what claims are supported by experiments;
5. what prior art must be cited;
6. what security details should remain private.
